# Sri Hanuman Chalisa

Read **Sri Hanuman Chalisa** in Hindi, Odia, English, Bengali, Tamil, Telugu, Kannada, Malayalam, Gujarati, Marathi, Punjabi, and Assamese.

- Choose a language from the chips
- Or type a language name in search (`odia`, `oriya`, `tamil`, `bangla`...)
- Optionally show English meaning under each verse

Live site (after GitHub Pages is enabled): https://codergirlbaisakhi.github.io/SriHanumaChalisa/

## Local run

```bash
npm install
npm start
```

Then open http://localhost:4200/

## Build

```bash
npx ng build --configuration production --base-href /SriHanumaChalisa/
```

The original hymn is the 16th-century Awadhi composition of Tulsidas (public domain). Other languages show the same verses in that script for recitation.
